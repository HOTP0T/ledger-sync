# Bundled UI fonts

The same fonts as Gnos3 (Gnos3/static/assets/fonts), bundled so nothing is fetched from a
CDN. All are licensed under the SIL Open Font License 1.1 (full text: `OFL-1.1.txt`); none
declares a Reserved Font Name.

## Geist-1.7.2-Variable.woff2, Geist-1.7.2-Italic-Variable.woff2, GeistMono-1.7.2-Variable.woff2

Unmodified, from the npm package `geist@1.7.2` (font version 1.800).

Copyright (c) 2023 Vercel, in collaboration with basement.studio
Copyright 2024 The Geist Project Authors (https://github.com/vercel/geist-font)

## Inter-3.19-Gap.woff2, Inter-3.19-Gap-Oblique.woff2

Modified version of Inter 3.019: only the characters Geist lacks (Greek, the narrow no-break
space used by French number formatting, thin / figure spaces, some currency signs, extended
Latin, Cyrillic extensions, symbols), `slnt` axis pinned to 0 and -10. Built with fontTools.

Copyright 2020 The Inter Project Authors (https://github.com/rsms/inter)
